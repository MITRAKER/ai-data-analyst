# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text on that page is the rule. This page gives a
short summary and explains how to report a problem.

## Our pledge

We want this project to be a welcoming, harassment-free place for everyone,
whatever their background, identity or level of experience. Many people here are
learning, so questions are always welcome.

## Scope

The code of conduct applies in every project space: issues, pull requests, code
reviews, commit messages and discussions. It also applies when someone represents
the project in public, for example in a post or a talk about it.

## Expected behavior

- Be kind and patient, especially with people who are new to programming or to
  open source.
- Respect different opinions, experiences and ways of working.
- Give feedback about the work, not the person. Accept feedback in the same way.
- Own your mistakes. Apologize to anyone affected, and learn from them.
- Think about what is best for the whole community, not only for yourself.

## Unacceptable behavior

- Sexual language or images, and unwanted sexual attention of any kind.
- Insults, personal or political attacks, and comments made only to provoke
  (trolling).
- Harassment, in public or in private.
- Sharing someone's private information, such as their home address, without
  their clear permission.
- Any other behavior that would be out of place in a professional setting.

## Reporting a problem

If someone's behavior worries you, contact the maintainer through GitHub:
<https://github.com/MITRAKER>. Please do not report conduct problems in a public
issue.

If the problem involves the maintainer, or you would rather not contact them, you
can report it to GitHub directly. Every comment has a **Report content** option in
its **...** menu, and every user profile has a **Block or report** option.

The maintainer reviews every report promptly and fairly, and keeps the reporter's
identity and the details as private as possible.

## Enforcement

The maintainer decides what counts as a violation and what to do about it. The
maintainer may remove, edit or reject comments, commits, code, issues and other
contributions that break this code of conduct.

The response depends on how serious the problem is. The Covenant's enforcement
guidelines describe four steps:

1. **Correction:** a private, written warning that explains what was wrong. A
   public apology may be requested.
2. **Warning:** a warning with consequences if the behavior continues, such as no
   contact with the people involved for a set time.
3. **Temporary ban:** a ban from any interaction with the project for a set time.
4. **Permanent ban:** for a pattern of violations, harassment of a person, or
   aggression toward or disrespect of groups of people.
